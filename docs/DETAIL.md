# Qoder

Open **Qoder** in the DSH sidebar to switch between Qoder CN and Qoder Global. Both providers can be enabled at once and use the sign-in and credits from their matching desktop app.

- **Account & credits** shows connection status, plan and remaining credits. Refresh applies to the selected channel.
- The credit chip next to the model picker shows the selected Qoder channel's balance and opens its details.
- **Models** lets you search the catalog and choose which models appear in the DSH model picker.
- **Diagnostics** shows runtime details and lets you reconnect an individual channel.

The global runtime downloads when a global model is first used. The integration accepts text input and DSH executes tools.
